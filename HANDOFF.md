# Хендофф: «Домашняя касса» (личный учёт финансов)

## Кто и зачем
Пользователь: Bessaract, веб-дизайнер и креативный директор. Хочет контролировать личные финансы с телефона на Android.
Как с ним работать: отвечать по-русски, неформально, коротко. Термины расшифровывать прямо в тексте. На новой задаче сначала предложить варианты и согласовать подход, и только потом писать код («не бежать впереди паровоза»).

## Согласованный план
- Этап A (сделан): веб-приложение, один файл `kassa.html`, опубликовано как приватная страница в Claude. Задача этапа: обкатать категории, экраны и привычку вносить траты.
- Этап B (следующий): настоящее Android-приложение с виджетом на рабочем столе. Виджет показывает «осталось на сегодня» и «свободно до конца месяца», плюс кнопка «+» для быстрого ввода траты.

## Требования (решения пользователя)
- Доступ только у него. Никакого общего бюджета и шаринга.
- Счета раздельно (карты, наличные, вклады), есть переводы между счетами.
- Рубли плюс другие валюты, курс задаётся вручную; операция фиксирует курс на день внесения.
- У каждой траты поле «на кого»: Я, Варя, Ира, Мама (по умолчанию «Я», список редактируется).
- Постоянные доходы и расходы с числом месяца, проводятся одним нажатием.
- Лимит на день, лимиты по категориям, цели накоплений, графики.
- Кредиты: видно, как уменьшается остаток, прогноз даты закрытия.
- Интерфейс должен быть удобным и аккуратным, таблицы (Google Sheets, Excel) отклонены.

## Что есть в `kassa.html`
Чистый HTML/CSS/JS без сборки и библиотек. Экраны: Сегодня, История, План, Долги и цели, Отчёт, Настройки. Формы открываются нижним листом, собираются одним генератором `openForm`.

Модель данных:
- `config`: `accounts[{id,name,cur,init}]`, `cats[{id,name,type:'exp'|'inc',limit}]`, `persons[]`, `rates{USD:число}`, `rec[{id,type,name,amt,day,cat,acc}]`, `loans[{id,name,total,balance,pay,rate,day}]`, `goals[{id,name,target,saved,monthly}]`.
- Операции лежат по месяцам: документ `m-ГГГГ-ММ` = `{items:{id: tx}}`.
- `tx`: `{id,ts,t:'exp'|'inc'|'tr',amt,cur,rub,cat,acc,to,who,d:'ГГГГ-ММ-ДД',note,ref?}`. `ref` = `{k:'rec'|'loan'|'goal',id,princ?}` связывает операцию с планом, кредитом или целью.
- Системные категории: `c_loan` (Кредиты), `c_goal` (Накопления).

Формулы:
- Свободно до конца месяца = постоянные доходы + разовые доходы − (постоянные расходы + платежи по кредитам + плановые взносы на цели) − обычные траты месяца. «Обычные» = без `ref`.
- Лимит на день = (свободно + потрачено сегодня) ÷ оставшиеся дни, включая сегодня. Осталось на сегодня = лимит − потрачено сегодня.
- Платёж по кредиту: проценты за месяц = остаток × ставка ÷ 1200; остальное уменьшает долг. Удаление платежа возвращает остаток.
- Баланс счёта = начальный остаток ± операции; чужая валюта пересчитывается через рубли.

Хранение сейчас: облачная база страницы Claude, личная ветка пользователя (`data/users/<id>/`), запасной вариант `localStorage`. Из Claude Code эта база недоступна.

Опубликованная страница: https://claude.ai/artifact/GBU4rB9BwnQn9ryX8PtK8a (приватная, правки публикуются по этому же адресу).

Дизайн (версия 2, выбор пользователя): смесь киберпанка и Fallout. Только тёмная тема: чёрный фон, зелёный фосфорный текст, строчки развёртки, кислотно-жёлтый акцент, бирюзовые заголовки, малиновый для перерасхода, срезанные углы, шрифты Tektur и JetBrains Mono. Первый вариант (светлый, синий акцент) отклонён. На телефоне дизайн ещё не проверен, пользователь отзыв по нему пока не дал.

## Чего нет
- Экспорта и импорта данных (JSON/CSV). Нужен до переезда на этап B, иначе внесённые операции не перенести.
- Автоматического курса валют.
- Периода «от зарплаты до зарплаты»: сейчас считается календарный месяц.
- Сквозной проверки на телефоне: проверен только синтаксис скрипта.

## Этап B: предложение по стеку (согласовать с пользователем до старта)
- Kotlin + Jetpack Compose (набор инструментов Google для интерфейса Android).
- Room (локальная база данных на телефоне) с той же моделью данных.
- Jetpack Glance (библиотека для виджетов рабочего стола).
- Сборка APK (установочный файл Android) через Android Studio или Gradle из терминала.
- Резервная копия: экспорт/импорт JSON в файл.
Альтернатива попроще: обернуть существующий веб-код в Capacitor (оболочка, превращающая веб-страницу в приложение) и дописать нативный виджет отдельно. Быстрее, но виджет всё равно пишется на Kotlin.

## Порядок действий в Claude Code
1. Прочитать `kassa.html` целиком.
2. Спросить пользователя, что он уже проверил на телефоне и что хочет поменять.
3. Предложить варианты стека для этапа B и дождаться выбора.
4. Проверить окружение: установлены ли Android Studio, JDK, Android SDK.
5. Только после этого писать код.
