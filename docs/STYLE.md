# Гайд по стилю и анимациям (дизайн v3 «мех-HUD»)

Утверждён 2026-10-21. Живой эталон: `prototype/style.html` (открывается двойным кликом, без сети).
Если гайд и прототип расходятся, прав прототип: в нём точные значения.

## Суть
Hard-surface sci-fi интерфейс (стилистика Arknights, Evangelion, техно-ярлыков): плоские панели с вырезами,
штриховки, мелкий служебный текст, контурные «трассы», японские подписи-ярлыки, редкие глитчи.
Только тёмная тема. Акцентные плашки белые и лаймовые.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| bg | #0E0F0F | фон экрана |
| surface | #17191A | тёмные панели, навигация, нижний лист |
| raised | #212425 | иконки, чипы, нажатое |
| line | #34383A | рамки, линии, трассы |
| grey | #8A8F91 | приглушённый текст, служебные строки |
| text | #E9EAE4 | основной текст на тёмном |
| paper | #EFEFEA | белые информационные панели |
| ink | #0B0C0C | текст на белом и лайме |
| lime | #C8FF00 | акцент |
| bad | #FF3D2E | перерасход |
| warn | #FF9F0A | предупреждения |

Правила:
- Лайм и белый только для главного: сумма на сегодня, основная кнопка, активная вкладка, «+». Остальное в оттенках угля.
- При перерасходе красный заменяет лайм на том же элементе (главная плашка становится красной).
- На лайме и белом текст всегда `ink`.

## Иероглифы (упрощённый китайский, с 2026-10-22; до этого — японский)
Только декоративные ярлыки рядом с русским текстом, смысл всегда продублирован по-русски.
Шрифт: PingFang SC на Маке/iOS, Noto Sans CJK SC на Android.
Словарь: 今天 Сегодня, 记录 История, 计划 План, 支出 Расходы, 负债 Долги, 报告 Отчёт, 设置 Настройки, 余额 остаток,
超支 перерасход, 限额 лимит, 月底 конец месяца, 本月 этот месяц, 结余 остаток месяца, 待付 ждут оплаты, 付款 платежи,
收入 доходы, 日历 по числам, 目标 цели, 存钱 отложить, 删除 удалить, 取消 отмена, 恢复 восстановить, 开发中 в разработке,
空 пусто, 剩 осталось (дней), 记账本 «книга учёта» (логотип).
Иконки категорий — один иероглиф: 食 продукты, 茶 кафе, 车 транспорт, 家 дом, 乐 развлечения, 讯 связь, 医 здоровье,

В заголовке экрана — вертикальный ярлык из двух знаков с лаймовой чертой слева. В навигации иероглифы на 50% прозрачности.

## Формы (v3.1, утверждено 2026-10-22)
Референс — «жетон»: крупные срезы углов и куски того же цвета, оторванные от панели.
- **Панель A** (главная): срез 22 dp слева сверху, ступенька 8 dp в верхней грани, срез 34–42 dp справа сверху,
  срезы 26–28 dp снизу, вырез 8 dp по левому краю в нижней части. Снаружи: оторванная планка слева (5 dp, зазор 4 dp),
  штриховка в нижнем вырезе слева, рельс 2 dp сверху справа — строго параллельно верхней грани и срезу, зазор 6 dp.
  Справа штриховки нет.
- **Панель B** (вторая, белая): срез 30 dp справа сверху, вырез 8 dp по правому краю ниже 38% с отдельной планкой в нём,
  «язычок» снизу, оторванный уголок снизу слева, штриховка слева.
- **Панель C** (строки списков): два среза 12 dp по диагонали. Заполненная строка (операция, доход, платёж, цель) —
  рамка лайм 45% (#C8FF0073) и мягкий отсвет слева: градиент лайм 8% → прозрачный к 55% ширины поверх `surface`.
- **Строки-заглушки «Добавить…» и подсказки:** пунктирная рамка `line`, фон — матовое стекло:
  `surface` 55% + размытие фона 10 dp. В Android размытия «под элементом» нет — там плотнее: `surface` ~85%.
- Оторванные куски всегда цвета своей панели (при перерасходе краснеют вместе с ней).
- **Длинные кнопки:** цельная форма без разрезов. Срезы по углам и приподнятая «чёлка» на верхней грани:
  прямо → вверх → прямо → вниз → прямо. Отступы 26 dp по бокам, 24 сверху, 20 снизу; шрифт Tektur 800 / 14, без переноса.
  4 варианта одного языка (положение чёлки и размеры срезов):
  1) чёлка 24–66%, срезы TL 12 · TR 18 · BR 10 · BL 26; 2) 38–84%, 20 · 10 · 24 · 10;
  3) 12–50%, 10 · 22 · 12 · 20; 4) 30–62%, 16 · 14 · 20 · 14 (высота чёлки 5–7 dp).
  Вариант выбирается по тексту кнопки (стабильно); у кнопок на одном экране варианты не повторяются.
  Вторичная кнопка — та же форма контуром `line`.
- **Кнопка «+»:** квадрат 62 dp, два среза 12 dp по диагонали, без разрезов. Приподнята над навигацией.
- **Скруглений нет (с 0.6.2, 2026-10-22):** все вершины — острые срезы: панели, кнопки, чипы, поля, куски, строки, «+».
- **Стеклянные панели A/B** (макет пользователя в Figma): лайм 62% / белая 88%, размытие под панелью 5, зерно чёрное ~18%,
  свечение цвета панели (размытие 30, сдвиг 4 вниз, 70%, не просвечивает сквозь стекло), светлая кромка по контуру,
  оторванные куски — цвет панели 65%. Нажатие: панель утапливается (−14 по глубине) и наклоняется к пальцу до 7°, 120 мс, возврат 220 мс.
  Главная открывает «Историю», белая — «План». В Android размытия под элементом нет — плотнее заливка, остальное так же.

## Декор
Штриховка «////», стрелки ⇲, крестики-маркеры, серийники (SN 48-1508F), индекс экрана «01 02 03…»,
служебная строка сверху (KS-01 // дата // день недели). Не больше 2–3 декоративных деталей на панель.
Фон: сетка 24 dp почти невидимая (белый 2%) и 1–2 контурные трассы.

## Анимации
Движение механическое и быстрое, как у прибора: резкий старт, мягкая остановка, без «пружин».

| Токен | Значение | Где |
|---|---|---|
| t-fast | 120 мс | нажатия, переключатели, чипы |
| t-base | 220 мс | появление панелей |
| t-slow | 360 мс | нижний лист, смена экрана |
| ease-out | cubic-bezier(.2, 0, 0, 1) | всё появляющееся |
| ease-in | cubic-bezier(.4, 0, 1, 1) | всё исчезающее, ×0.7 времени |
| stagger | 45 мс | шаг между панелями при запуске |

- **Запуск экрана:** короткая загрузка «SYS.INIT … [OK]» (~0,7 с, только при холодном старте), затем панели
  появляются по очереди: сдвиг на 8 dp вверх + вспышка яркости.
- **Подсчёт цифр:** при изменении суммы разряды «перебираются» случайными цифрами и встают на место слева направо, 440 мс.
- **Нажатие:** проседание на 2 dp, масштаб 0.98, мгновенная инверсия цветов, короткая вибрация.
- **Нижний лист:** выезжает за 360 мс, затем вдоль верхней грани пробегает лаймовая линия.
- **Трассы:** по контурным линиям фона бежит лаймовый «ток», 7 с на круг.
- **Курсор ввода:** лаймовая черта, мигает раз в секунду.
- **Глитч:** случайно раз в 15–40 с — сдвиг и цветное расщепление заголовка или главной цифры на 180 мс,
  в 40% случаев плюс горизонтальная полоса через экран. Никогда при открытом листе ввода.
  В настройках: выкл / редко (по умолчанию) / часто.
- Всё движение отключается системной настройкой «Убрать анимации».
