# «Домашняя касса» — инструкция проекта

Личный трекер финансов Bessaract. Читать этот файл первым при любой работе в папке.
Подробности веб-версии — в HANDOFF.md (ссылку на страницу Claude там игнорировать: страница удалена).

## Правила общения
- Отвечать по-русски, неформально, коротко. Термины расшифровывать прямо в тексте.
- «Не бежать впереди паровоза»: на новой задаче сначала варианты и согласование, потом код.
- Вопросы задавать по одному, как в интервью.
- Дизайн не менять без явной просьбы.

## Жёсткие ограничения
- Доступ к данным только у пользователя. Никаких облачных аккаунтов, аналитики, синхронизации, сетевых запросов без его согласия.
- Все новые файлы — внутри этой папки.
- Логику, модель данных и формулы брать из kassa.html / HANDOFF.md, не изобретать заново.

## Решения от 2026-10-21 (этап B)
- Стек: Kotlin + Jetpack Compose (UI) + Room (локальная БД SQLite) + Jetpack Glance (виджет рабочего стола).
- Сборка APK: в облачной среде Claude. На Маке нет Android Studio, JDK и SDK — и ставить их не планируется.
- Установка: APK переносится на телефон и ставится вручную (разрешить установку из неизвестных источников).
- Телефон: Android 13–15. minSdk можно брать 26+, targetSdk актуальный.
- Данные: старт с чистого листа, перенос из веб-версии не нужен. Экспорт/импорт JSON всё равно нужен как резервная копия.
- Скилы/плагины/коннекторы не используются. Субагенты — для сверки формул JS↔Kotlin и для ревью кода.

## Модель данных (переносить 1:1)
- config: accounts[{id,name,cur,init}], cats[{id,name,type:'exp'|'inc',limit}], persons[], rates{USD:число},
  rec[{id,type,name,amt,day,cat,acc}], loans[{id,name,total,balance,pay,rate,day}], goals[{id,name,target,saved,monthly}].
- Операция tx: {id,ts,t:'exp'|'inc'|'tr',amt,cur,rub,cat,acc,to,who,d:'ГГГГ-ММ-ДД',note,ref?}.
  ref = {k:'rec'|'loan'|'goal', id, princ?} — связь с планом, кредитом или целью. «Обычные» траты = без ref.
- Системные категории: c_loan (Кредиты), c_goal (Накопления). Их нельзя удалить.
- persons по умолчанию: Я, Варя, Ира, Мама; первый — по умолчанию.
- Валюты: рубль базовый, курс задаётся вручную; операция хранит и amt в своей валюте, и rub по курсу на день внесения.

## Формулы
- fixed = Σ rec(exp).amt + Σ loans(balance>0).pay + Σ goals(saved<target).monthly
- free (свободно до конца месяца) = Σ rec(inc).amt + Σ разовых inc без ref − fixed − Σ exp без ref за месяц
- left = дней до конца месяца, включая сегодня
- dayLimit = (free + spentToday) / left; leftToday = dayLimit − spentToday
- Платёж по кредиту: interest = balance × rate / 1200; princ = min(balance, max(0, amt − interest)); balance −= princ.
  Удаление платежа возвращает princ в balance. Удаление взноса в цель уменьшает saved.
- Прогноз закрытия кредита: итерация по месяцам, если pay ≤ interest — «платёж не покрывает проценты».
- Баланс счёта = init ± операции; чужая валюта пересчитывается через rub.

## Экраны и виджет
- Экраны: Сегодня, История, План, Долги и цели, Отчёт, Настройки. Формы — нижний лист (bottom sheet).
- Виджет: «осталось на сегодня», «свободно до конца месяца», кнопка «+» → быстрый ввод траты.

## Дизайн (версия 2, утверждена)
- Только тёмная тема. Киберпанк + Fallout (Pip-Boy терминал).
- Цвета: фон #050806, поверхность #0B120D, утопленный #12201A, текст #B6F7C4, приглушённый #5FA877, линии #1F4A30,
  акцент #FCEE0A (кислотно-жёлтый), good #3DFF8B, bad #FF2E6C (перерасход), warn #FFB000, заголовки #2DE2E6 (бирюза).
- Шрифты: Tektur (заголовки/цифры), JetBrains Mono (текст). Срезанные углы, строчки развёртки, свечение текста.
- Полная CSS-спецификация — в <style> файла kassa.html.

## Чего ещё нет (бэклог)
- Экспорт/импорт JSON. Автокурс валют. Период «от зарплаты до зарплаты» вместо календарного месяца.
